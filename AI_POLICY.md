# AI Policy

AI tools may be used to assist with development in Phantom, including drafting code, documentation, tests, and problem analysis.

Contributors remain fully responsible for any code, documentation, or other content they submit. This includes correctness, security, licensing, maintainability, and whether the work is appropriate for the project.

## Expectations

- Contributors must understand the code they submit and be able to explain it.
- AI-generated output must be reviewed before submission.
- Contributors must verify that generated code works as intended and test it where relevant.
- Contributors must ensure that submitted material is compatible with the project license and does not infringe third-party rights.
- AI-generated code is held to the same standards as human-written code.
- Contributors should disclose the use of AI tools when asked or when the project requires it for transparency, but there is no blanket ban on AI-assisted work.

## Maintainer discretion

Maintainers may reject or request changes to any contribution that is low quality, unsafe, untested, unclear, or otherwise not suitable for the project, regardless of whether AI was used.

## Practical rule

Use AI as a productivity tool, not as a substitute for judgment. The contributor is responsible for the final result.
